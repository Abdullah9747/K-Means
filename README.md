# K-Means Clustering on Iris Dataset

This repository contains my implementation of the **K-Means Clustering** algorithm on the **Iris dataset**. Using unsupervised learning, I grouped the data into clusters to explore patterns and relationships between the features.

## Overview

The K-Means algorithm clusters the Iris dataset into groups based on the similarities of flower features. This project includes:

- **Clustering**: Applying K-Means to form clusters.
- **Visualization**: Displaying the clusters to understand the grouping.

## Dataset

The Iris dataset consists of 150 samples from three species:

- **Setosa**
- **Versicolor**
- **Virginica**

Each sample has four features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
